The file is `/flag`. I ran **7z** once with **sudo** to put `/flag` into a tar stream, then ran it again to print the stream's contents:
```
sudo -u root 7z a -ttar -an -so /flag | 7z e -ttar -si -so
```
This requires the active sudo policy to permit the invocation.

## Findings

I checked `sudo -l` and found that I could run **7z** as root. I found the protected file at `/flag`. The command below reads it into a tar stream, then prints the contents. It only works because of the **sudo** rule on this challenge.

## What I Learned

The stream options are normal **7z** features. The important part was the challenge's **sudo** rule, which let the first **7z** process read `/flag` as root. I checked the options in the [7-Zip source](https://github.com/ip7z/7zip/blob/main/CPP/7zip/UI/Common/ArchiveCommandLine.cpp).
